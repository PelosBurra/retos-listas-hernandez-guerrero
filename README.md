\## Conceptos aprendidos



Explique con sus palabras: lista simple, lista doble, lista circular,

ventajas/desventajas de cada una y un ejemplo de uso real.



Lista Simple: Los nodos contienen información, y se van trasladando en una sola dirección hacia la cabeza  

Lista Doble: Así como la anterior lista, los nodo tienen información, la diferencia radica en que se pueden trasladar hacia enfrente y atrás 

Lista Circular: Aquí no existe el final (null), por lo tanto el ultimo apunta al primero, aquí se pueden ser tanto como doble o simple



\-Ventajas

Simple: Traslado en una sola dirección

Doble: Traslado hacia atrás y enfrente

Lista Circular: Muy beneficioso para turnos, así también como rotaciones y ciclos



\-Desventajas

Simple: Si queremos eliminar algo necesitamos recorrer toda la lista

Doble: Hay que mantener los 2 punteros en el enlace

Lista Circular: No existe null al final
